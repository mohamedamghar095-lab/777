# برالايا — حالة التطوير

## تشغيل نسخة اللعب

1. افتح مجلد المشروع في Unity 6.
2. بعد اكتمال الاستيراد، افتح مشهدًا فارغًا أو أنشئ واحدًا، ثم اضغط **Play**.
3. ينشئ `BralaiaBootstrap` اللعبة تلقائيًا. إذا لم يظهر شيء، راجع نافذة **Console** بحثًا عن أخطاء تجميع.

## تشغيل اختبارات المحاكاة

1. افتح **Window → General → Test Runner**.
2. اختر **EditMode**.
3. اضغط **Run All**.

توجد اختبارات المحاكاة في `Assets/Tests/BralaiaWorldTests.cs` ضمن assembly اختبار خاص بالمحرر. لاختبار تغييرات جديدة، أضف حالات تغطي النتائج والموارد والملكية بعد كل إجراء.

## الميزات والنطاق الحالي

يحتوي النموذج على اختيار المناطق، عرض 2D/3D، اقتصاد وجيوش، ذكاء اصطناعي إقليمي بسيط، حرب وهجوم وسلام، وحفظ محلي. لا يوجد اتصال شبكي أو لعب جماعي حتى الآن. لا تستخدم الحملة المحلية مصدرًا موثوقًا للمنافسة الشبكية؛ ستحتاج اللعبة الجماعية خادمًا يصادق على الأوامر ويحفظ حالة العالم.

## خطوات التطوير التالية

- تثبيت دورة لعب وموازنة الاقتصاد والمعارك عبر الاختبارات.
- إضافة دبلوماسية وأحداث ومهمات مع اختبارات لكل قاعدة.
- نقل واجهة `OnGUI` الأولية إلى Unity UI عند توفر تصميم مرئي وأصول.
- تصميم بنية خادم سلطوي ومزامنة قبل بناء اللعب الجماعي.
