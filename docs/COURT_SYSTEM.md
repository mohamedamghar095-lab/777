# نظام المجلس والشخصيات

`BralaiaCourt` يضيف نموذجًا محليًا وحتميًا لثلاث شخصيات: الوزيرة ليان، قائد الحرس راشد، وأمينة الخزانة مريم. لكل مستشار ولاء ونفوذ وعلاقة ومهمة. تتيح واجهة النظام عقد جلسة أو تكليف مهمة، ويعالج النظام حدثًا دوريًا عند تقدم دور الحملة.

## نقاط الربط

- استدعِ `AdvanceTurn(world.Turn)` بعد تقدم دور الحملة؛ النظام يمنع معالجة الدور نفسه مرتين.
- استخدم `HoldAudience(id)` لتحسين العلاقة والولاء، أو `AssignProject(id)` لإسناد مهمة ملائمة للمنصب.
- اعرض `Advisors` و`EventLog` في لوحة المجلس.
- احفظ `SaveToJson()` في مفتاح مستقل عن حفظ الحملة، واستعده عبر `LoadFromJson()`؛ فصل الحفظ يحافظ على توافق ملفات الحملات القديمة.

النظام منفصل عن واجهة اللعب الحالية عمدًا، لذلك لا تظهر لوحة المجلس تلقائيًا بعد إضافة هذا النموذج. اختبارات `BralaiaCourtTests` تغطي الشخصيات والتقدم والأحداث والحفظ والتحميل. شغّلها من **Window → General → Test Runner → EditMode**.
