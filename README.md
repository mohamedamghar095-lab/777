# برالايا — نموذج استراتيجي أولي

مشروع Unity قابل للتشغيل، يقدّم نواة لعبة استراتيجية عن عالم برالايا. النموذج نقطة بداية قابلة للتوسعة، وليس محاكاة كاملة لكل كائن في عالم ضخم.

## المزايا الحالية

- تسع مناطق قابلة للاختيار من الخريطة أو القائمة.
- التبديل بين عرض ثنائي الأبعاد من أعلى وعرض ثلاثي الأبعاد مائل.
- اقتصاد مبسط: الخزانة، الطعام، السكان، التنمية، القوى البشرية والاستقرار.
- تجنيد الجيوش، تطوير الزراعة، وجباية الضرائب.
- دول آلية تتوسع إلى الأراضي المستقلة وتعزز جيوشها.
- إعلان الحرب، هجوم على منطقة معادية مجاورة، معارك مجردة، وطلب السلام.
- حفظ الحملة وتحميلها محليًا على الجهاز باستخدام Unity PlayerPrefs.
- اختبارات EditMode للمحاكاة، ومشهد لعب مدرج مسبقًا في إعدادات البناء.

## التشغيل

1. افتح مجلد المستودع في Unity 6.
2. انتظر اكتمال الاستيراد، وافتح `Assets/Scenes/Bralaia.unity`.
3. اضغط **Play**. ينشئ `BralaiaBootstrap` الخريطة والكاميرا والواجهة عند بدء التشغيل.
4. استخدم زر **عرض 3D / عرض 2D** للتبديل، وانقر المناطق أو اخترها من القائمة.
5. جرّب التجنيد والزراعة والضرائب، ثم اضغط **الدور التالي**. للحرب، اختر منطقة معادية، أعلن الحرب، ثم هاجمها.
6. شغّل الاختبارات من **Window → General → Test Runner → EditMode → Run All**.

## التحكم

- `WASD` أو الأسهم لتحريك الكاميرا.
- عجلة الفأرة للتقريب والإبعاد.

## حدود النموذج

الذكاء الاصطناعي قائم على قواعد خفيفة، وليس ذكاءً بشريًا أو نموذجًا لغويًا. المعارك استراتيجية ومجردة؛ لا توجد وحدات متحركة أو قتال تكتيكي بعد. الحفظ محلي، ولا يوجد تعدد لاعبين أو خادم شبكي حتى الآن. اللعب الجماعي يتطلب خادمًا موثوقًا يصادق على الأوامر ويحفظ حالة العالم؛ لا يمكن اعتباره جاهزًا بمجرد إضافة اتصال مباشر بين العملاء.

المنطق الأساسي مكتوب بـ C#؛ لا حاجة إلى استخدام جميع لغات البرمجة في مشروع Unity.
